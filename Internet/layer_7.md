# Layer 7

The Application Layer (Layer 7) of the OSI model is the topmost layer and provides services directly to end-users and applications. It enables network access to software applications like web browsers, email clients, file transfer tools, and more.

## Web Browsing

| Protocol | Description |
|:--------:|:-----------:|
| HTTP (HyperText Transfer Protocol) | Foundation of data communication for the web. |
| HTTPS (HTTP Secure) | Encrypted HTTP using TLS/SSL. |
| SPDY/HTTP2/HTTP3 | Enhanced versions of HTTP for performance improvements.  |

## Email

| Protocol | Description |
|:--------:|:-----------:|
| SMTP (Simple Mail Transfer Protocol) | Sends email between servers. |
| POP3 (Post Office Protocol v3) | Downloads email from server to client (deletes from server). |
| IMAP (Internet Message Access Protocol) | Syncs email with server (keeps messages on the server). |

## File Transfer

| Protocol | Description |
|:--------:|:-----------:|
| FTP (File Transfer Protocol) | Transfers files over TCP; supports authentication. |
| SFTP (SSH File Transfer Protocol) | Secure FTP over SSH. |
| TFTP (Trivial FTP) | Simple, no-authentication file transfer over UDP. |
| FTPS (FTP Secure) | FTP with SSL/TLS encryption. |

## Remote Access and Management

| Protocol | Description |
|:--------:|:-----------:|
| SSH (Secure Shell)  | Secure command-line access and file transfers. |
| Telnet | Remote command-line access (insecure, mostly obsolete). |
| RDP (Remote Desktop Protocol) | GUI-based remote desktop access (used by Windows). |
| SNMP (Simple Network Management Protocol) | Monitors and manages network devices. |

## Domain Name System

| Protocol | Description |
|:--------:|:-----------:|
| DNS (Domain Name System) | Resolves domain names to IP addresses. |
| mDNS (Multicast DNS) | Local network name resolution (used in zero-config setups like AirPlay). |

## Messaging and Communication

| Protocol | Description |
|:--------:|:-----------:|
| XMPP (Extensible Messaging and Presence Protocol) | Real-time messaging (used in chat systems). |
| SIP (Session Initiation Protocol) | Initiates, maintains, and terminates VoIP calls. |
| RTP (Real-time Transport Protocol) | Delivers audio and video over IP networks. |

## Network Services

| Protocol | Description |
|:--------:|:-----------:|
| DHCP (Dynamic Host Configuration Protocol) | Assigns IP addresses and network info dynamically. |
| NTP (Network Time Protocol) | Synchronizes clocks across networked systems. |
| LDAP (Lightweight Directory Access Protocol) | Accesses and manages distributed directory info (e.g., user logins). |

## Others

| Protocol | Description |
|:--------:|:-----------:|
| NNTP (Network News Transfer Protocol) | Transfers Usenet articles. |
| SMB (Server Message Block) | File and printer sharing over networks (Windows). |
| AFP (Apple Filing Protocol) | File sharing in Apple environments.  |
| MQTT (Message Queuing Telemetry Transport) | Lightweight messaging for IoT devices. |
| CoAP (Constrained Application Protocol) | RESTful protocol for constrained networks (IoT). |
